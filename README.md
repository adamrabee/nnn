# ملعب الدروس — تعلّم باللعب

منصة تعليمية عربية (RTL) تحوّل محتوى الدرس الذي يكتبه المعلم إلى ألعاب ومنافسات ومغامرات تعليمية تُعرض على شاشة الفصل أو السبورة الذكية. المعلم يتحكم في كل شيء؛ لا حسابات ولا أجهزة للطلاب، ولا تُحفظ أي نتائج.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # اختبارات محرك الدروس
npm run typecheck
npm run build
```

## ما الذي يعمل الآن (المرحلة الأولى)

| الجزء | الحالة |
|---|---|
| إدخال الدرس (العنوان، المادة، الصف، المحتوى) + 5 دروس نموذجية | ✅ |
| تحليل الدرس محليًا: مفاهيم، تعريفات، مصطلحات، تسلسلات، تصنيفات، علاقات، أهداف، أهم المعلومات، ما يحتاج شرحًا | ✅ |
| اقتراح الألعاب حسب بنية الدرس، مع ذكر السبب إن لم يكفِ المحتوى | ✅ |
| مراجعة وتعديل كل سؤال قبل اللعب | ✅ |
| 9 ألعاب قابلة للعب: معركة المعرفة، تحدي القمة (سلّم + وسائل مساعدة)، صح أم خطأ، طابِق المعنى، ذاكرة المصطلحات، تحدي الترتيب، الحروف المبعثرة، اكتشف الخطأ، غرفة الهروب (مغامرة بقصة تناسب الدرس) | ✅ |
| أوضاع المنافسة: فريق ضد فريق (2–6)، لاعب ضد لاعب، الفصل كله، تعاوني، المعلم ضد الطلاب، فريق عشوائي | ✅ |
| نقاط على الصحة والتفسير والتعاون وإكمال التحدي (لا نقاط على السرعة)، نجوم، سلاسل، إنجازات | ✅ |
| تغذية راجعة تشرح «لماذا» مع اقتباس من الدرس، وتمثيل بصري للأعداد | ✅ |
| 10 إعدادات وصول جاهزة قابلة للجمع + تحكم دقيق | ✅ |
| مؤثرات صوتية مُركّبة بـ Web Audio (تعمل دون إنترنت) + موسيقى هادئة اختيارية + نصوص مرئية للأصوات | ✅ |
| قراءة صوتية بصوت المتصفح العربي (إن وُجد) | ✅ |
| ملء الشاشة، لوحة المفاتيح، شاشة النهاية مع سؤال ختامي | ✅ |
| وضع الذكاء الاصطناعي (اختياري) | ✅ يعمل فقط إذا ضُبط مفتاح على الخادم |
| بطولة داخل الفصل، والألعاب في صفحة «المكتبة» المعلَّمة «قيد التطوير» | ⏳ المرحلة 2 و3 |

## وضع الذكاء الاصطناعي (اختياري)

الوضع المحلي هو الافتراضي ولا يرسل أي نص خارج المتصفح. لتفعيل وضع Claude على Vercel أضف متغيرات البيئة على الخادم:

```
ANTHROPIC_API_KEY=...            # مطلوب — لا يوضع أبدًا في الواجهة الأمامية
ANTHROPIC_MODEL=claude-opus-5-5  # اختياري
```

- `api/status.ts` يخبر الواجهة هل المفتاح مضبوط فعلًا؛ إن لم يكن، يظهر الوضع «غير مُعدّ» ولا يمكن اختياره.
- `api/generate.ts` يرسل العنوان والمادة والصف ونص الدرس فقط، ويطلب مخرجات JSON مقيّدة بمخطط (`api/_schema.ts`).
- الواجهة تتحقق من كل عنصر مقابل نص الدرس: تحذف المفاهيم غير الموجودة في النص، وتعلّم الأسئلة غير المطابقة بعلامة «راجِع».
- محليًا، `npm run dev` لا يشغّل دوال `api/`؛ استخدم `vercel dev` لتجربة هذا الوضع.

## الخصوصية

- لا حسابات، لا تسجيل دخول، لا ملفات شخصية، لا قاعدة بيانات للدرجات، لا تحليلات، لا تصدير.
- النقاط والنتائج في ذاكرة الصفحة فقط وتختفي عند التحديث.
- يُحفظ آخر درس كتبه المعلم في `localStorage` على جهازه فقط، ويمكن حذفه من صفحة الخصوصية.
- إعدادات الوصول تُحفظ محليًا على الجهاز.

## البنية

```
src/engine/      محرك الدرس → اللعبة (لا يعتمد على React)
  analyze.ts     تحليل النص العربي بالقواعد
  generate.ts    توليد الأسئلة والعبارات والأزواج والتسلسلات من التحليل فقط
  catalog.ts     تعريف الألعاب وشروط توفرها وترتيب الاقتراحات + خارطة الطريق
  adventure.ts   قصص المغامرات ومراحلها
src/games/
  boards/        لوحات تحدٍّ قابلة لإعادة الاستخدام (اختيار، صح/خطأ، ترتيب، مطابقة، ذاكرة، حروف، خطأ)
  games.tsx      الألعاب = تركيب لوحات + قواعد (جولات، سلّم، مراحل مغامرة)
  session.tsx    الفرق والأدوار والنقاط والإنجازات (في الذاكرة فقط)
src/ai/client.ts الوضع المحلي ووضع الذكاء الاصطناعي + التحقق من الاستناد إلى الدرس
src/audio/       المؤثرات الصوتية والقراءة الصوتية
src/state/       إعدادات الوصول وحالة الدرس
api/             دوال Vercel (المفتاح على الخادم فقط)
```

### إضافة لعبة جديدة

1. أضف معرّفها إلى `GameId` في `src/engine/types.ts`.
2. عرّفها في `GAMES` داخل `src/engine/catalog.ts` مع `available()` التي تشرح ما ينقص.
3. أعد استخدام لوحة من `src/games/boards/` أو أنشئ لوحة جديدة بواجهة `onResult` / `onNext`.
4. أضف الحالة في `GameRunner` داخل `src/games/games.tsx`.
